# PriorityPack

Priorización algorítmica de paquetes para optimizar el procesamiento
de envíos.

## Descripción

PriorityPack es un sistema diseñado para analizar información de
envíos a partir de archivos CSV y generar una priorización de paquetes
utilizando algoritmos de procesamiento y ordenamiento.

El proyecto busca analizar cómo diferentes estrategias algorítmicas
pueden mejorar la eficiencia del procesamiento de grandes volúmenes
de envíos.

## Objetivo

Desarrollar un sistema capaz de priorizar paquetes de manera eficiente
y analizar experimentalmente el rendimiento de diferentes algoritmos,
con énfasis en estrategias basadas en Divide & Conquer.

## Tecnologías

- Python
- Flask
- Pandas
- HTML
- CSS
- JavaScript

## Estructura

- `app/algorithms/`: implementaciones de algoritmos.
- `app/services/`: lógica de procesamiento, priorización y análisis.
- `app/models/`: modelos de datos.
- `app/templates/`: interfaz HTML.
- `app/static/`: CSS y JavaScript.
- `data/raw/`: datos originales.
- `data/processed/`: datos procesados.
- `tests/`: pruebas.
- `docs/`: documentación académica.

## Estado

Estructura inicial del proyecto. La fórmula de prioridad y los algoritmos definitivos se definirán después de revisar el dataset.
